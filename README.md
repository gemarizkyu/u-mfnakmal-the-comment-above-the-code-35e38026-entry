## What this is

An entry for the make.fun bounty **"The Comment Above the Code"**. The program writes a single funny, painfully honest line — the kind of comment a developer leaves above fragile production code that everyone is too scared to touch — to `/output/entry.txt` (max 200 characters). Entries are judged head-to-head, so the line has to land on its own.

The line it writes:

```
// The column is still called 'temp' because in 2016 someone was sure this was temporary. It runs payroll now.
```

## Run it

```bash
python3 main.py
```

Outside the sandbox, point it at your own output folder:

```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program is fully deterministic: it writes the same fixed line on every run. No clock, no randomness, no network calls, and no model calls.
